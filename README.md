# Pearl VIP Services — Bilingual PWA

Free installable airport VIP concierge academic demo. English / Arabic.

## Features
- Reception time, reception type and airport escort
- Beverage, meal, seating and privacy preferences
- Luxury transportation requests
- Interactive FAQ-based VIP assistant (not a real AI model)
- Manually advanced journey tracking (not live flight data)
- Local booking confirmations and booking history

## Publish on GitHub Pages
Upload **the contents of this ZIP** (not the ZIP itself) into the root of your existing GitHub repository, replacing the existing files. Commit changes. Under Settings > Pages, deploy from `main` and `/ (root)`. Wait for deployment, then refresh the website and installed PWA.

## Limitations
All bookings are demo-only and stored in localStorage on the current browser/device. The assistant provides scripted answers and journey progress is manually updated; no real airport booking, shared backend, flight tracking or live AI is integrated. Do not enter sensitive personal information.
